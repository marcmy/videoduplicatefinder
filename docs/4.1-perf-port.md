# 4.1 performance port

This branch starts from the 4.1 application architecture and selectively ports the useful engine work from `perf/native-hwaccel-from-crashfix`.

Ported so far:

- Native FFmpeg decoder and batched gray-frame extraction
- D3D11 gray-byte scaling paths
- Capability-scoped hardware fallback behavior
- Independent CPU headroom for normal and partial-clip duplicate matching
- Multi-sample pHash matching quorum with a configurable 60% default
- Comparer mode selection based on the selected pair rather than transient thumbnail-loading state
- Comparer stale-frame, zoom, pan, and swipe-coordinate correctness fixes

The 4.1 per-drive SSD/HDD media-extraction scheduler remains unchanged. Classic 4.0 DataGrid and monolithic MainWindow customizations are intentionally excluded.
